# Kesavan N - Premium Personal Portfolio Website

A futuristic, modern, and responsive personal portfolio website for **Kesavan N**, a **1st-year Civil Engineering student** at Mount Zion College of Engineering and Technology with an interest in design.

## Features & Highlights
- **Futuristic Dark & Blueprint Aesthetic**: Deep navy/black background (`#030712`), cyan/electric-blue glowing gradients, architectural truss schematics, and CAD crosshairs.
- **Glassmorphism Design**: Sleek backdrop blurs, luminous borders, and fluid transitions.
- **Full Navigation**: Home, About, Education, Skills, Design, Projects, Achievements, Contact.
- **Interactive Contact Section**:
  - Direct 1-tap **Call** button (`tel:6382166603`)
  - **Copy Number** button with automated toast notification feedback
- **Authentic 1st-Year Academic Narrative**: Accurately reflects Kesavan's status as a 1st-year undergraduate building his skills in C programming and engineering design without any exaggerated or fictional claims.

## How to View the Website

### Option 1: Instant Browser View (Zero-Setup)
Simply double-click [`index.html`](./index.html) in Windows File Explorer or open it with any web browser (Chrome, Edge, Firefox). Everything runs out of the box with responsive layouts and interactive features.

### Option 2: Run with Vite & React
If you have Node.js installed and wish to run the React development server:
```bash
npm install
npm run dev
```
